# Imágenes de la memoria

Guardar aquí las imágenes de tablas y gráficas que se generen a partir de
experimentos reales. Usar nombres descriptivos y enlazarlas desde
`../memoria.md` con rutas relativas `img/nombre.png`.

Cada figura debe indicar variantes, aperturas, número de partidas, unidades
y, cuando corresponda, incertidumbre. Conservar los datos de origen en
`../../experiments/` y explicar cómo se obtiene la figura. Todavía no hay
resultados del jugador ni figuras experimentales generadas.
